# NOVA — Trabalho de Programação

Projeto NOVA Life + NOVA Quest com autenticação Supabase e NOVA AI através da Edge Function `nova-ai`.

## Desenvolvimento

Abre `index.html` com o Live Server. Mantém a configuração pública do Supabase em `supabase-config.js`. As chaves privadas de IA ficam apenas em Supabase → Edge Functions → Secrets.

## Segurança

Não guardes passwords, chaves secretas ou tokens neste repositório. Se uma palavra-passe administrativa foi anteriormente publicada no GitHub, muda-a e limpa-a do histórico.

## Git

Este pacote não inclui `.git`. Para preservar o teu repositório, copia o conteúdo desta pasta para a pasta existente do projeto, sem apagar a pasta `.git`.
